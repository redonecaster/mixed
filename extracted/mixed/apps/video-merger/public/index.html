VIDEO MERGER API

ادمج فيديوهاتك بسهولة

أضف روابط فيديو عامة أو ارفع ملفاتك، ثم رتّب المقاطع قبل الدمج.

توثيق API
POST /api/jobs
{ "videos": ["https://example.com/one.mp4", "https://example.com/two.mp4"] }
POST /api/jobs/{id}/process
GET /api/jobs/{id}
GET /api/jobs/{id}/video (supports Range)
DELETE /api/jobs/{id}
